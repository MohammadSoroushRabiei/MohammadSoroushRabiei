## 🔭 About me

Embedded systems developer with **industrial experience** in sensor drivers and industrial-communication
firmware for STM32-based **DCIM** (data-center infrastructure management) products. I work at the boundary of
hardware and software — from driver-level timing (Timer Input Capture + DMA) to neural inference on an ESP32-S3.

- 🔭 Currently: **Embedded Systems Developer @ Kian Pardaz Nagh-e Jahan** — sensing subsystem of a DCIM product
- 🌱 Interests: TinyML / on-device (online) learning, IoT architecture, privacy-first cloud-free smart environments
- 🎓 B.Sc. final project: **IoT-based smart home with on-device Edge AI** (supervised by Dr. Amir Khorsandi)
